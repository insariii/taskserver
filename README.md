Сначала запускаем сервер:
python server.py
После этого в другом окне терминала запускаем клиента:
python client.py
Можно запустить несколько клиентов одновременно.Все клиенты работают с одним общим списком задач

Команды
Добавить задачу
/add Купить кофе
Показать все задачи
/list
Отметить задачу как выполненную
/done 1
Удалить задачу
/delete 1
Завершить работу клиента
/quit
Например после команды /add Купить кофе
список будет выглядеть вот так:
1. [ ] Купить кофе

После команды:
/done 1
задача станет:

1. [x] Купить кофе
После команды:
/delete 1
задача будет удалена из общего списка.

Одновременная работа клиентов
Сервер создаёт отдельный поток для каждого подключившегося клиента:
threading.Thread(
    target=handle_client,
    args=(client_sock, addr),
    daemon=True
).start()
Поэтому несколько клиентов могут одновременно подключаться к серверу и отправлять команды

Общий список задач
Список задач находится на сервере:
tasks = []
Все потоки клиентов работают с одним и тем же списком

Синхронизация
Для безопасной работы с общим списком используется:
tasks_lock = threading.Lock()
Перед чтением или изменением списка задач используется:
with tasks_lock:
Это необходимо, чтобы несколько потоков не изменяли список задач одновременно
